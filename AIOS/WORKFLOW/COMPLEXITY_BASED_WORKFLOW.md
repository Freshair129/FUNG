# Complexity-Based Workflow

C0 Micro
- Single file
- No design
Steps: Understand -> Implement -> Test

C1 Feature
- Small feature
Steps:
Research
Plan
Implement
Review
Test

C2 Cross-module
- Multiple modules
Steps:
Research
Architecture
Task decomposition
Implementation
Integration test
Review
Docs

C3 Architecture
- System-wide change
Steps:
Research
Requirements
Trade-off analysis
ADR
Design review
Implementation
Validation
Documentation

Escalate when uncertainty or risk is high.
