# Historical task archive

This directory preserves task briefs and reports from earlier documentation
audits. Their findings, commands, and paths describe work performed at the time
and are not current repository guidance. Current traceability sources are
[Appendix D](../../../../appendices/D-traceability.md), the registry at
[requirements registry](../../../../requirements/REGISTRY.md), the `@req` contract
checked by `npm run test:traceability`, and scoped preflight reports.

Former links under `docs/.rwang-tasks/` remain available as compatibility
pointers. Use this archive for the original task records.
