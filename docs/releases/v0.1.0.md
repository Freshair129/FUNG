# FUNG v0.1.0 — Windows x64 Public Beta

This is the first self-contained FUNG Desktop public beta for Windows x64 with
Live Meeting transcription running locally.

## Download

[Download `FUNG-windows-x64-setup.exe`](https://github.com/Freshair129/FUNG-Releases/releases/latest/download/FUNG-windows-x64-setup.exe)

The public binary is distributed from the binary-only `FUNG-Releases`
repository so it is downloadable without access to the private source
repository.

## Included

- Real microphone and optional system-audio capture.
- Live local transcription through a bundled CPU `int8` runtime.
- Portable CPython 3.11.9, `faster-whisper` 1.2.1, and a pinned local `small`
  model; normal first use does not download the model.
- Durable local audio chunks and transcript rows through GenesisBlockDB.
- Installer asset: `FUNG-windows-x64-setup.exe`.

## Install and integrity

Download size is approximately 491 MB. The exact release asset is 515,089,576
bytes with SHA-256:

`f67a78e0b216628d19335646342eea20575d5c7b5a16cccf7daf32c6b780d414`

The installer is not Authenticode-signed. Windows SmartScreen may display a
warning; verify the SHA-256 before installing.

## Current boundaries

- Windows x64 only.
- CPU transcription only; this release makes no CUDA/GPU claim.
- Browser microphone capture and mobile publication are not included.
- Post-meeting AI summary requires a separately running compatible local LLM
  endpoint; Live Meeting capture, transcription, and persistence do not.

## Verification

The candidate passed the focused frontend/Python suites, controlled Rust
library suite (`197/197`), 30-second real mic plus system-loopback UAT, installed
runtime transcription, visible-window launch smoke, and production-style web
CTA check.
