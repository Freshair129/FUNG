Interactive states

State must explain what happened.

ready

Primary action

One clear action per active stage; keep an accessible name and a visible keyboard focus.

ready

Secondary action

Keep supporting actions visually quieter than the current primary action.

recording

Recording state

Show recording with text and a persistent visual signal; never rely on color alone.

local

Local execution

Name the on-device or local runtime so local processing is not mistaken for cloud work.

inferred

Inferred result

Mark generated or inferred content as pending review until the user confirms it.

focus

Focus indicator

Use a visible focus outline independently from material, border or shadow styling.

empty

Empty and unavailable

Explain the next available action and why an unavailable capability cannot run.

error

Error and recovery

State what happened, whether source data remains safe, and how to retry or recover.
