# FUNG Design System Publishing — historical proposal

This proposal documented the former Mobile-only Markdown payload and HTML renderer. It was superseded on 2026-10-16 when FUNG consolidated token ownership across Desktop, Mobile, Web and Landing.

## Current publishing contract

| Layer | Canonical path | Rule |
| --- | --- | --- |
| Shared token source | docs/FUNG_Design_System_v0.1.0/tokens/fung.tokens.json | DTCG 2025.10 tokens; FUNG-only metadata in the namespaced extension. |
| Runtime CSS and contrast report | docs/FUNG_Design_System_v0.1.0/tokens/fung.tokens.css and docs/FUNG_Design_System_v0.1.0/qa/CONTRAST_REPORT.md | Generated by build_tokens.py; do not edit by hand. |
| Shared interactive board | docs/design-system/index.html | Generated cross-surface reference and token catalog. |
| Quiet Archive presentation | docs/design-system/brand/index.html | Generated from the same token source. |
| Mobile compatibility entry | docs/Mobile/DESIGN_SYSTEM.md | Pointer only; Mobile behavior remains in PRODUCT_UX_SPEC.md. |

Use node scripts/design_system.mjs render to build every generated output and node scripts/design_system.mjs check to verify they are current.

## Historical decision

The former proposal kept human-readable Mobile documentation beside a structured payload and generated HTML to avoid hand-edited preview drift. That principle remains; token authority moved to the shared DTCG file, so the obsolete embedded JSON format and Mobile-only source claim were removed.
